# 學習路徑頁面：需求與開發說明

對應頁面：[learning_path_static.html](learning_path_static.html)

## 需求

1. 依 `lessons` 每筆資料的第三欄判斷課程進度：`"O"` 表示已完成，`"X"` 表示尚未完成。
2. 學習路徑須可水平捲動，且每次停止操作時，畫面中央只對應一張課程卡片。
3. 在底部提供自訂捲動條與箭頭圖示。
4. 箭頭代表「最後一個已完成課程」的位置；當捲動條滑塊中心與箭頭重合時，畫面中央必須是最後一張 `"O"` 卡片。
5. 捲動條滑塊的寬度需固定，不可因螢幕寬度、卡片數或內容總寬而改變。
6. 不可讓多張卡片對應到相同的捲動條位置；拖曳或點擊捲動條後，應吸附到唯一最近的卡片。

## 資料格式

```js
const lessons = [
  ["章節編號", "課程名稱", "O 或 X", "備註"],
];
```

- 第三欄為 `"O"`：節點套用 `.done` 樣式，並納入完成進度計算。
- 第三欄為 `"X"`：節點套用 `.error` 樣式，不納入完成進度計算。
- 最後一個 `"O"` 是由 JavaScript 動態找出；調整 `lessons` 的 O/X 後，不須手動修改箭頭位置。

## 實作結構

```text
.progress-shell                 固定覆蓋層的定位容器
├─ #viewport                    可水平捲動的課程內容
│  └─ #track
│     └─ .lesson × 課程數量
└─ #customScrollbar             自訂捲動條，不隨內容移動
   ├─ .custom-scrollbar-track   捲動軌道
   ├─ #progressMarker           最後完成課程的箭頭
   └─ #scrollbarThumb           固定寬度滑塊
```

`#progressMarker` 不放在 `#viewport` 裡，避免它跟著可捲動內容一起移動。

## 捲動條定位規則

滑塊寬度由 CSS 變數固定設定：

```css
.custom-scrollbar {
  --thumb-width: 72px;
}
```

JavaScript 使用下列一對一映射：

```text
滑塊左側位置 = (目前 scrollLeft / 最大 scrollLeft) × 可移動距離
箭頭位置 = 滑塊寬度 / 2 +
           (最後一個 O 的置中 scrollLeft / 最大 scrollLeft) × 可移動距離
```

因此箭頭的水平位置永遠是「最後一個 O 對應滑塊的中心」，而固定滑塊寬度不會因內容量改變。

## 互動行為

- 拖曳課程內容：停止後由 `snapToNearest()` 吸附到最接近畫面中央的單一卡片。
- 滾輪水平移動：停止後同樣吸附到最近卡片。
- 拖曳自訂滑塊：即時換算 `scrollLeft`，放開後吸附到最近卡片。
- 點擊自訂軌道：跳至對應位置，並吸附到最近卡片。
- 視窗尺寸改變：重新計算第一、最後卡片的留白、自訂滑塊位置與箭頭位置。

## 維護注意事項

- 若需修改滑塊視覺寬度，只調整 `--thumb-width`；不需調整 JavaScript 計算式。
- 新增、刪除或調整課程完成狀態時，只修改 `lessons` 陣列。
- 若所有課程都是 `"X"`，箭頭會自動隱藏。
