# 小抄集開發說明

## 目的

小抄集提供學生快速閱覽重點筆記的介面，並可從課程地圖的冊、單元或知識點進入。清單內容需依目前選取的課程節點篩選；上層節點顯示其下轄知識點的小抄合集。

目前展示頁：`student/cheat-sheet-collection-demo.html`

課程地圖來源頁：`student/learning-history-demo.html`

## 已完成內容

- 小抄集採用與錯題集一致的右側直列選擇器。
- 右側的 `☰` 按鈕可展開為完整小抄清單；點選項目會更新中央的小抄內文與描述。
- 中央區僅保留：
  - 小抄標題、時間與標籤
  - 小抄內文
  - 小抄描述
- 已移除收藏、更多選單、知識點清單、複習提示與開始複習按鈕。
- 小抄內文區有內部捲動，外層工作區固定在頂欄以下的可視高度。
- 已移除 `min-width: 1080px`，並加入 900px、640px 斷點，避免窄畫面橫向超框。

## 課程地圖串接

課程地圖節點右側的「小抄」按鈕連至：

```text
cheat-sheet-collection-demo.html?scope=<node-id>
```

### 關聯與去重規則

小抄與知識點採多對多關聯：一份小抄可以標記多個知識點，一個知識點也可以對應多份小抄。

- 從知識點進入時，只顯示關聯該知識點的小抄。
- 從單元進入時，彙整所有下轄知識點的小抄，依小抄 `id` 去重。
- 從冊進入時，彙整所有下轄單元與知識點的小抄，依小抄 `id` 去重。

因此，上層節點的統計數量是「不重複小抄數」，不應直接加總下轄知識點各自顯示的數量。

範例：小抄「根號化簡檢查清單」同時關聯「平方根概念」與「根式化簡」。兩個知識點各顯示 1 張該小抄，但其共同的單元只計為 1 張。

目前的節點與小抄數量如下：

| 節點 | scope | 小抄數量 | 篩選規則 |
| --- | --- | ---: | --- |
| 第一冊 | `book-1` | 11 | 匯入所有知識點小抄，依小抄 ID 去重 |
| 實數 | `unit-1` | 4 | 匯入 K1～K3，依小抄 ID 去重 |
| 指數與對數 | `unit-2` | 2 | 匯入 K4 |
| 數列與級數 | `unit-3` | 5 | 匯入 K5 |
| 平方根概念 | `knowledge-1` | 2 | 僅顯示 K1 小抄 |
| 根式化簡 | `knowledge-2` | 2 | 僅顯示 K2 小抄 |
| 數線與座標 | `knowledge-3` | 1 | 僅顯示 K3 小抄 |
| 指數律 | `knowledge-4` | 2 | 僅顯示 K4 小抄 |
| 等差、等比級數 | `knowledge-5` | 5 | 僅顯示 K5 小抄 |

## 假資料

目前資料寫在小抄集頁面的 JavaScript 中，作為互動、階層篩選與多對多去重測試。每筆小抄都有唯一 `id`；同一份物件可被多個知識點參照。

```text
knowledgeSheets
  ├─ knowledge-1：平方根概念
  ├─ knowledge-2：根式化簡
  ├─ knowledge-3：數線與座標
  ├─ knowledge-4：指數律
  └─ knowledge-5：等差、等比級數
```

`sheetsByScope` 會根據網址參數決定顯示來源；單元與冊層級透過 `uniqueSheets()` 依小抄 `id` 合併並去重下層資料。

## 版面規則

- 桌面與平板：左側導覽、中央閱讀區、右側小抄選擇列。
- 右側選擇列預設僅顯示序號；展開後顯示完整標題與所屬知識點。
- 中央 `.detail` 採固定可用高度；`.sheet-body` 使用 `overflow: auto` 捲動。
- 900px 以下：縮小側欄、間距與字級，小抄內文改單欄。
- 640px 以下：隱藏左側導覽，保留右側選擇列與展開面板。

## 後續串接建議

1. 將目前假資料換為 API 回傳資料，至少包含 `id`、`title`、`sent_at`、`tags`、`content`、`description`。
2. 以小抄與知識點的中介關聯表（例如 `cheat_sheet_knowledge`）保存多對多關係。
3. 後端依 `scope` 解析冊／單元／知識點階層，回傳已排序且依小抄 ID 去重的清單，前端不再自行合併資料。
4. 小抄無資料時維持目前的空狀態提示：「這個知識點目前還沒有小抄」。
5. 若重新加入收藏或分享功能，應先定義其後端狀態與權限，再新增右上角操作按鈕。
