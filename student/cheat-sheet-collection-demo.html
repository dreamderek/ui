常用的求和公式等比級數等差級數

級數

將數列 <an> 的前 n 項依序相加，所成的式子稱為級數；
Sn = a1 + a2 + … + an

等差級數的和

<an> 為等差數列，公差為 d，其前 n 項和為：Sn = (a1 + an)n / 2其中 (a1 + an) / 2 為此數列的等差中項。

等比級數的和

<an> 為等比數列，公比為 r。Sn = a1(1 − rn) / (1 − r)，r ≠ 1Sn = na1，r = 1

單利與複利

一開始存入或借取的金額為本金 a；一段時間後產生的額外金額為利息，利息與本金的比率為利率 r。
(1) 1 + 2 + 3 + … + n = n(n+1) / 2
(2) 1² + 2² + … + n² = n(n+1)(2n+1) / 6
(3) 1³ + 2³ + … + n³ = [n(n+1) / 2]²
