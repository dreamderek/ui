# MetaMath 學生端平板 UI 展示

展示檔案為 `tablet-ui-demo.html`。此為可直接開啟的獨立 HTML 原型，最小顯示寬度為 768px，針對橫向平板操作設計。

## 固定區域

- 左側功能列：主頁、評鑑、學習歷程、訊息、我的帳號。
- 頂部功能區：使用者問候、學校／群組切換、通知與帳號頭像。

## 主工作區

主工作區以左右滑動切換首頁功能，已完全移除「最新批閱」。

1. 今日焦點
2. 今日重點與評鑑
3. 需要加強的知識點
4. 老師訊息
5. 我的解題步驟
6. 錯題與複習
7. 能力定位

## 操作

- 在中央工作區向左或向右滑動，可切換功能。
- 點擊右上圓點，可直接切換指定功能。
- 鍵盤左右方向鍵也能切換。
- 水平位移超過 55px 才換頁，避免上下捲動時誤觸。

## 串接建議

正式版可由下列資料來源驅動：

- `todayFocus`
- `assessments`
- `knowledgeSupport`
- `teacherMessages`
- `solutionSteps`
- `reviewQueue`
- `abilityProfile`

左側欄可串接既有路由；中央滑動區維持為首頁內部功能切換。
