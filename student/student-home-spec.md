# MetaMath 學生端平板 UI 規格

展示檔案為 `tablet-ui-demo.html`。此為可直接開啟的獨立 HTML 原型，針對橫向平板工作區設計。

## 本次需求

1. 縮小左側工具列與上方資訊列的占比。
2. 移除中央工作區上方的文字標題、左右切換按鈕與頁碼。
3. 將工作區下方原本的頁面指示點改為可直接點選的功能卡。
4. 下方功能卡尺寸必須一致，並在工作區下方水平置中。
5. 功能與面板排序調整為：學習總覽、評量任務、能力分析、知識地圖、學習歷程、複習建議、訊息通知。

## 固定區域

- 左側功能列：主頁、評鑑、學習歷程、訊息、我的帳號。
- 頂部功能區：使用者問候、學校／群組切換、通知與帳號頭像。
- 中央工作區：顯示目前選擇的功能面板。
- 工作區底部：提供七張功能捷徑卡，作為面板的直接切換入口。

## 功能順序與對應

| 順序 | 功能卡 | 圖示 | 對應面板 |
| --- | --- | --- | --- |
| 1 | 學習總覽 | `⌂` | 學習總覽 |
| 2 | 評量任務 | `✓` | 評量任務 |
| 3 | 能力分析 | `▥` | 能力分析 |
| 4 | 知識地圖 | `▦` | 知識地圖 |

## 開發細節

| 項目 | 實作內容 |
| --- | --- |
| 左側工具列 | 寬度由 `104px` 調整為 `78px`；品牌與導覽按鈕同步縮小。 |
| 上方資訊列 | 高度由 `99px` 調整為 `68px`，並縮小內距。 |
| 工作區上方區域 | 已移除 `.screen-heading` 及其中的標題、頁碼、上一頁與下一頁按鈕。 |
| 功能捷徑 | 以 `#featureNav` 取代圓點導覽；每張 `.feature-card` 固定為 `94px × 58px`。 |
| 對齊方式 | 功能卡容器採用 Flexbox，透過 `justify-content: center` 保持水平置中。 |
| 面板排序 | 初始化時依指定順序重新附加 `.panel` 節點，確保顯示內容、快捷卡與切換索引一致。 |

## 操作規則

- 點選功能卡時，工作區切換至對應面板，並更新功能卡的 `.active` 狀態。
- 在中央工作區向左或向右滑動，可切換功能。
- 鍵盤左右方向鍵可切換功能。
- 水平位移超過 55px 才換頁，避免上下捲動時誤觸。
- 功能卡具有焦點樣式與 `aria-label`，可透過鍵盤操作並由輔助技術辨識。

## 串接建議

正式版可由下列資料來源驅動：

- `todayFocus`
- `assessments`
- `knowledgeSupport`
- `teacherMessages`
- `solutionSteps`
- `reviewQueue`
- `abilityProfile`

左側欄可串接既有路由；中央工作區則維持為首頁內部功能切換。
