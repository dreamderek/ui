# 評鑑任務平板 Demo 規格

對應展示頁：[assessment-task-demo.html](assessment-task-demo.html)。本頁為學生端評鑑功能的互動式 UI Demo，定位為固定視窗的平板 App，而非可上下捲動的網頁。

## 設計需求

1. 畫面固定為平板操作尺寸，禁止瀏覽器頁面捲動。
2. 左側工具列與上方資訊列固定；中央工作區占據其餘可視範圍。
3. 評鑑任務以卡片呈現，但不使用長直式清單。
4. 上方中央區域顯示目前選取任務的滿版摘要；下方使用橫向任務卡軌道。
5. 點選下方任務卡，只更新上方的聚焦任務；點選聚焦區主按鈕後才進入滿版任務詳情。
6. 任務數量多時，使用者可直接在下方卡軌左右滑動查看其餘卡片。

## 任務狀態

| 狀態 | 用途 | 視覺提示 |
| --- | --- | --- |
| 未交卷 | 尚未送出的任務，包含未開始與進行中。 | 琥珀色狀態標籤。 |
| 申覆中 | 已送出申覆，等待老師處理。 | 藍色狀態標籤。 |
| 已完成 | 已完成並可查看結果、能力分析或錯題建議。 | 綠色狀態標籤。 |

## 下方任務卡軌道

下方卡軌兩側使用堆疊圖示按鈕作為任務類型切換控制：

| 位置 | 按鈕內容 | 切換結果 |
| --- | --- | --- |
| 左側 | 已完成 | 卡軌改為顯示所有「已完成」任務卡。 |
| 右側 | 未交／申覆 | 卡軌改為顯示「未交卷」與「申覆中」任務卡。 |

卡軌實作為水平 Flex 容器，使用 `overflow-x: auto` 與 `scroll-snap-type: x proximity`，使卡片數量增加時仍可在固定平板畫面內橫向瀏覽，不影響整頁高度。

## 切換動畫

切換時不保留舊卡軌的收合、淡出或上下縮放動畫；新類型卡片會直接替換。

| 目標類型 | 動畫規則 |
| --- | --- |
| 已完成 | 卡片個別由左向右以水平壓縮後展開，並帶有短暫的依序延遲。 |
| 未交／申覆 | 整條卡軌以右側為錨點，整體向左同步揭露展開；不使用逐張延遲、追趕、壓縮或滑入效果。 |

切換邏輯會在下一個瀏覽器繪製週期加入動畫類別，確保卡片替換後能穩定播放轉場。

## 中央工作區互動

1. 初始顯示「未交／申覆」卡軌與第一張任務的聚焦摘要。
2. 點選卡軌中的任務卡，更新中央任務名稱、狀態、期限、預估時間、完成進度與主操作按鈕。
3. 點選主操作按鈕，切換至中央滿版任務詳情。
4. 詳情頁的返回按鈕會回到先前選取的任務類型與卡軌。

## 主要實作

- 全頁與工作區使用 `height: 100vh`、`min-height: 0`、`overflow: hidden`，避免產生瀏覽器捲軸。
- 任務資料以 `taskData` 與 `taskOrder` 管理；每筆資料包含 `state`、`status`、標題、摘要、進度、期限與操作文案。
- `renderRail(group)` 依群組建立下方任務卡。
- `updateFocus(id)` 更新中央聚焦區。
- `switchRail(group)` 處理左右堆疊按鈕的類型切換與展開動畫。
- 已完成群組使用 `card-expand-right`；未交／申覆群組使用 `rail-expand-left`。
