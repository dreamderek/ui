# account-demo.html 開發說明

## 帳號頁

帳號頁位於 `student/account-demo.html`，為學生端的帳號設定展示頁。

### 頁面區塊

- 基本資料：暱稱、真實姓名、性別、教材版本、出生日期與個人簡介。
- 安全設定：登入方式、聯絡資訊與帳號驗證狀態。
- 學校資訊：學校、班別與認證資訊。
- 通知偏好：評鑑通知與系統提醒的 Email 站外通知開關。
- 語言與地區：介面語言與時區設定。

### 基本資料編輯

點選「編輯」後可修改文字欄位，並啟用教材版本下拉選單與出生日期選擇器。

- 點選「確認更新」後，保留此次修改並回到唯讀狀態。
- 點選「取消編輯」後，還原本次尚未確認的修改。

### 導覽

帳號頁左側選單順序為：基本資料、學校資訊、安全設定、通知偏好、語言與地區。

各設定區塊使用 `data-view` 連結到同名的內容區塊；新增設定頁時，應同時加入對應的按鈕與內容區塊。

## 本機預覽

在專案根目錄啟動靜態伺服器後，開啟：

`http://127.0.0.1:4173/student/account-demo.html`

例如：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

## 聚焦模式規格

學生端頁面可使用「聚焦模式」協助辨識目前可操作的物件。模式以 `body.focus-mode` 作為唯一狀態類別，並以固定的全畫面暗幕呈現。

### 觸發條件

- 左下角的 `?` 輔助按鈕（`.help`）切換聚焦模式。
- 啟動時，`body` 加上 `focus-mode`；按鈕的 `aria-pressed` 設為 `true`。

### 關閉條件

- 聚焦模式啟動後，點擊畫面任意位置即關閉。
- 若點擊的是連結、按鈕或可輸入元件，應先正常執行該元件原本的操作，再同步關閉聚焦模式。
- 再次點擊 `.help` 按鈕亦可關閉模式，並將 `aria-pressed` 更新為 `false`。

### 高亮物件限制

只高亮可直接操作的元件，並讓它們位於暗幕上方：

- 連結：`a`
- 按鈕：`button`
- 已啟用的輸入與選擇欄位：`input:not(:disabled)`、`select:not(:disabled)`
- 正在可編輯的文字欄位：`[contenteditable="true"]`

不要高亮靜態文字、資訊卡、版面容器或已停用的控制項。以帳號頁為例，非編輯狀態的教材版本與出生日期為停用狀態，必須隨暗幕變暗；進入編輯模式後才可被高亮。

### 側欄選單

透明底的側欄連結與帳號設定選單按鈕，需要在聚焦模式下補上原本的淺色背景，否則雖位於暗幕上方仍會看起來變暗。

- 左側主導覽連結使用白色底；目前頁面維持原本的 `--soft` 選取色。
- 帳號選單按鈕使用白色底；目前選取項維持 `#edf6e9`。

其他學生端頁面新增此功能時，應沿用上述觸發、關閉與高亮範圍，避免將非互動內容誤標示為可操作。
